# 🍽️ Zomato Clone Website

A responsive **Zomato-inspired landing page** built using **HTML5, CSS3, and JavaScript**. This project recreates the modern look and feel of Zomato's homepage while focusing on clean UI design, responsive layouts, and interactive user experience.

> 🚀 This project was created to strengthen my front-end web development skills and practice building real-world website clones.

## ✨ Features

- 🎨 Modern Zomato-inspired user interface
- 📱 Fully responsive layout
- 🔍 Search bar for restaurants, cuisines, and dishes
- 🍕 Hero section with Zomato branding
- ⚡ Interactive hover animations using JavaScript
- 🖱️ Click animation on the main image
- 💡 "Why Choose Us" section showcasing features
- 🦶 Clean and minimal footer
